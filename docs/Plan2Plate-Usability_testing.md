## TESTING PLAN:
This usability testing aims to evaluate the effectiveness and usability of a meal-planning
platform Plan2Plat in collaboration with Mercator. Our goal is to determine whether users
can:
- Easily decide what to cook
- Create meal plans
- Generate grocery list
- Order groceries
The test will be conducted on at least three participants, each representative of a key
persona. Participants will be asked to complete realistic tasks while using the thinking aloud
method.
## RESEARCH DESIGN:
## Section Duration
## Introduction 3-5min
## Interview 5min
## Tasks 15-20min
## Follow-up questions 5-10min

The tested product will be an interactive prototype, focusing the core features.

## SUMMARY:
TASK 1: Find a meal you would cook for today’s dinner.
This task tested whether users can quickly choose a meal without a problem or too much
decision fatigue.
Results: All users completed the task. Some users needed a bit longer than expected to
chose a meal. One user noted the lack of filters for recommendations.

TASK 2: Generate a meal plan for the next 3 days.
This task tested the difficulty of mel plan creation.
Results: All users completed the task and found it very simple and obvious.

TASK 3: Change the breakfast option for day 1.
This task tested whether users can easily edit a plan.
Results: One user was a bit confused at first, but all completed the task successfully.

TASK 4: Order everything from your shopping list.
This task tested the integration between meal planning and grocery shopping.
Results: All users said that it lacks some clarity, some were unsure if all the product were
added to the cart.

TASK 5: Find meals that are currently discounted.
This task evaluated whether users can find discounted meals without issues.
Result: All users completed the task, mostly without issues. However it was noted, that
maybe the discount symbol should be bigger and more visible.

Overall, visual clarity needs to be improved a bit. We also need to add more filtering options.
One of the users was wondering if they can only purchase a single food product – without
purchasing the whole meal. As of now this functionality has not been added, but we must
consider adding it in the future.
