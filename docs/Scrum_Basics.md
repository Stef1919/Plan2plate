# Plan2plate

## 1 Sprint 0 – Project Planning and Preparation

The goal of this project is to develop a meal planning web application. The website will
have user accounts, to help us build recommendations. The application allows users to
browse meals, add them to a cart, create meal plans, and view their meal history...

### 1.1 Tools

- Frontend: React
- Backend: Node
- Styling: CSS
- Version Control: GitHub
- Management Tool: Trello

### 1.2 Initial Application Features

The first prototype of the application have:

- Meal browsing interface
- Recipe viewing
- Meal planning by days
- Shopping cart for selected meals
- Meal history tracking

## 2 Sprint 1 – Prototype Implementation and Redesign

Sprint 1 focuses on implementing the first functional prototype of the application and
improving the design based on user testing results.

### 2.1 Sprint 1 TO-DO List

The following tasks will be implemented during Sprint 1:

- Implement meal interaction
    - Enable users to click on a meal and open the detailed recipe view.
- Improve the Get Inspired feature
    - Display meal suggestions clearly.
    - Allow users to add meals directly to the shopping cart.
    - Allow users to add meals directly to the meal plan.
- Implement Meal History
    - Allow users to view previously created meal plans.
    - Allow users to open old meal plans and review what meals were consumed.
- Improve cart functionality
    - The Add to cart button will only add items to the cart.
    - Remove automatic redirection to the order page.

## 3 Sprint 2 – User Accounts and Personalization

Sprint 2 focuses on introducing user accounts and personalization features. The goal of
this sprint is to allow users to create profiles and define their lifestyle preferences, which
will later be used to improve meal recommendations and planning.

### 3.1 Sprint 2 TO-DO List

- Implement user registration and login functionality.
- Create user profiles where users can store personal preferences.
- Implement lifestyle role selection for users.
- Store user information and preferences in the backend database.
- Connect lifestyle roles with the meal recommendation system.
- Allow users to update their lifestyle role in profile settings.
- Ensure secure handling of user data and authentication.
