# USER STORIES
## Jakob the Math Teacher:
Story 1: My work keeps me extremely busy – I can work between 8 an 14h a day. I want to
generate a weekly meal plan in under 15min so that I can save time and reduce decision
fatigue.
- User can generate weekly meal plan from dashboard.
- System generates 7 days of meals – breakfast, lunch and dinner.
- User can replace any single meal without regenerating the whole week.
- User then saves the weekly plan.

Story 2: Since I am extremely busy and unsure how much work I’ll have on a daily basis, I
often forget to buy some key ingredients for my meals. I’d like a shopping list so I don’t
forget ingredients.
- After making a meal plan, user can auto add ingredients to the shopping list.
- Duplicate ingredients are merged.
- User decides he doesn’t need a specific ingredient and removes it.
- List can then be exported or directly added to the shopping cart.

Story 3: On some weeks I don’t want to spend additional time grocery shopping after work. I
want to order all ingredients directly from Mercator so I don’t need to visit the store.
- After shopping list creation, user clicks “Add all to cart” button.
- System automatically adds all of the ingredients and re-routes the user to the cart.
- User can choose delivery or pickup.
- User can pre-pay or pay upon delivery/pickup.
- User receives order confirmation.

## Tina the Psychology Student
Story 1: I struggle with decision making a lot. I just want simple daily meal suggestions to
chose from.
- User clicks on “Get inspired”.
- A new page opens with random meal suggestions.
- User can then decide to filter the suggestions by “easy to make”.
- The system returns curated suggestions to user preferences.
- User can then select a meal and add it to weekly meal plan.

Story 2: Student life keeps me on a tight budget, therefor I always try to find the best deals
and save on money.
- User pulls current Mercator weekly discounts.
- Meals with discounted ingredients are flagged.
- Price comparison shows how much user saves “You save _€”.

Story 3: My indecisiveness makes me shop frequent and in small amounts. Since I often
change my mind, I would prefer 3-4 days meal plan to a 7 days plan.
- User can change the meal planning duration from 7 days to 3 or 5 days.
- Shorter plans can also be added to the cart.
- User can later extend plan to a full week plan.

## Marina the Health-Conscious Accountant
Story 1: As a physically active person, I want nutritionally balanced meal plans that support
my calorie goals.
- User can select “Active Lifestyle” preference.
- System automatically calculates calories per meal.
- Protein and carbs are displayed for every meal.
- Nutrition recalculates if meal is switched.

Story 2: Since my week can get busy, I like to meal prep. I want recipes that are able to stay
in the fridge for 2 to 3 days.
- System automatically flags meals that can be meal prepped.
- Each meal that can be meal prepped also displays for how many days it can be
stored.

Story 3: I love to meal plan. I want my Sunday meal-planning to take 30min or less, so I like
to re-use old recipes.
- Users can navigate to meal history tab.
- In meal history tab they can see all the past meals they bought.
- User can also access past meal plans and can reuse them.
